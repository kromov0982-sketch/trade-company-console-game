# Торговая компания

Консольная пошаговая стратегия на C# / .NET 10, без сторонних библиотек.
ASCII-карта и таблицы, русские подсказки, текстовые команды.

## Запуск

Дважды нажмите `run.cmd` или запустите его из cmd. Локальный SDK расположен
в `.tools/dotnet`; первая сборка может занять несколько секунд.

## Первый прибыльный рейс

```text
рынок дубрава
купить 1 древесина 30
ехать 1 перекрёсток
далее 2
рынок перекрёсток
продать 1 древесина 30
сохранить
```

Введите `помощь` для всех команд. Цель — получить 5000 монет наличными;
после достижения цели игра продолжается. Сохранение ручное, один слот:
`saves/company.json`. Команда `продолжить` загружает его. Выход — `выход`.

Повозка вмещает 60 единиц любого товара. Новый транспорт стоит 500 монет,
склад на 300 единиц — 400. Рейс стоит 8 монет за день пути, сумма списывается
при отправлении. Покупки транспорта доступны в любом городе.
Склад позволяет оставить товар в городе и освободить повозку для нового рейса.

Цены зависят от специализации города и его запасов. Для каждой единицы партии
цена пересчитывается, поэтому сумма сделки отличается от первой цены,
умноженной на количество. У продавцов есть наценка. Производство и потребление
каждый день приближают запас к местному равновесию; еженедельная ярмарка
создаёт дополнительный спрос. События детерминированы.

Это первый прототип: без конкурентов, кредитов, автоматических маршрутов
и собственных производств. При исчерпании средств можно загрузить сохранение
или перезапустить игру для новой компании.

## Разработка

```bat
.tools\dotnet\dotnet.exe restore --configfile NuGet.Config
.tools\dotnet\dotnet.exe build -c Release --no-restore
.tools\dotnet\dotnet.exe run -c Release -- --self-test
```

- `Game.cs`: состояние, экономика, маршруты и сохранения.
- `Ui.cs`: карта, рыночные таблицы и справка.
- `Program.cs`: обработка команд.
- `SelfTest.cs`: проверки инвариантов экономики и сохранения.

Официальный SDK: https://dotnet.microsoft.com/download/dotnet/10.0

## Автономная версия для Windows

Готовый `release/TradeCompany-Windows-x64.zip` можно отправить другому человеку.
После распаковки запускается `TradeCompany.exe`; установка .NET не требуется.
Архив рассчитан на 64-разрядную Windows 10/11. Для повторной публикации есть
`publish-windows.cmd` (на компьютере разработчика нужен интернет).


## Экран игры

Игра открывается в обновляемом консольном экране: компания и выбранный рынок
слева, команды справа, последнее сообщение и строка ввода снизу. История
команд и сообщений не сохраняется. Сохранение самой партии остаётся ручным.
Рекомендуемый размер окна — 110 × 34, минимальный — 76 × 24.
При запуске окно разворачивается автоматически. Меню и игровой экран заново
компонуют содержимое при изменении размера окна, не оставляя старых кадров.

- `рынок ГОРОД` переключает таблицу цен.
- PageUp / PageDown прокручивают сведения о компании.
- Стрелки, Home / End, Backspace / Delete редактируют ввод; Esc очищает строку.
- День меняется только по команде `далее`.
- При запуске главное меню предлагает начать новую игру или загрузить сохранение.
- Команда `меню` возвращает в главное меню без автоматического сохранения.

`Dashboard.cs` отвечает за экран, `Session.cs` — за выполнение команд.

## Совместная игра по локальной сети

Оба компьютера должны находиться в одной локальной сети и использовать одну
версию игры. Первый игрок выбирает «Создать сетевую игру» и сообщает второму
показанный IPv4-адрес. Второй выбирает «Подключиться» и вводит этот адрес.
Хосту может потребоваться разрешить игре доступ к частным сетям в окне
брандмауэра Windows. Игра использует TCP-порт 47777.

У каждого игрока свой торговец: отдельные деньги, повозки, грузы, склады и цель
в 5000 монет. Общими остаются рынки, цены и время, поэтому покупка одного игрока
меняет запас и цену товара для второго. Каждый игрок может независимо открыть
нужный рынок. В сетевой игре `далее` не принимает
число дней: сначала оба игрока вводят `далее`, затем проходит один день.
Готовность обоих отображается слева. Команда `меню` разрывает соединение.
