# Шрифты интерфейса

- Cormorant Garamond Semibold — заголовки окон и карточек.
- Cormorant Garamond Semibold Italic — названия городов на карте.
- Alegreya Regular — описания, журнал событий, основной текст.
- Alegreya Sans Regular — кнопки, таблица рынка, поля и денежные показатели.

Источник: https://github.com/google/fonts (ofl/cormorantgaramond, ofl/alegreya, ofl/alegreyasans).
Шрифты включены в проект; лицензии SIL Open Font License сохранены рядом.
